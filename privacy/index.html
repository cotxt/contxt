수능 영단어 게임

시행일 · 최종 수정일: 2026년 10월 22일

컨텍스트컴퍼니 주식회사(contxt company, 이하 “회사”)는 수능 영단어 게임 앱과 회원·점수·랭킹 서비스를 운영합니다. 이 방침은 서비스에서 어떤 개인정보를 처리하고, 언제 삭제하며, 이용자가 권리를 행사하는 방법을 안내합니다.

회원 탈퇴는 앱에서 직접 할 수 있습니다.

게임 선택 화면 → 내 정보 → 회원 탈퇴에서 비밀번호를 확인하고 탈퇴를 완료하면 계정, 서버 게임 기록, 점수·랭킹 및 모든 로그인 세션이 삭제됩니다.

1. 처리하는 정보와 이용 목적

  • 회원가입·로그인: 이메일, 비밀번호, 닉네임, 학생 그룹(초등학교·중학교·고등학교·N수생)을 입력받습니다. 계정 식별, 로그인과 그룹별 랭킹에 이용합니다. 서버에는 비밀번호 원문 대신 복원이 어려운 해시를 저장합니다. 생년월일은 수집하지 않습니다.
  • 출신(선택): 이용자가 직접 입력한 출신 정보를 서버에 저장하고, 내 정보와 회원 랭킹에 표시하는 데 이용합니다. 출신은 입력하지 않아도 가입할 수 있습니다.
  • 회원·학습 기록: 회원 ID, 가입 시각, 게임 종류, 배정된 문제 ID, 게임 시작·완료 시각, 정답 수, 획득 점수, 누적 점수와 완료 횟수를 저장합니다. 시간 보너스 게임은 서버 타이머의 시작·마감 시각, 정답 확인 시각, 정규화한 답의 단방향 해시와 시간 보너스를 함께 저장합니다. 게임 결과 검증, 중복 적립 방지, 레벨·계급·랭킹 제공에 이용합니다. 제출한 답안은 결과 검증에 사용하며 답안 원문을 DB에 보관하지 않습니다.
  • 로그인 유지·보안: 로그인 세션 ID, 생성·만료·폐기 시각과 리프레시 토큰의 해시를 저장합니다. 로그인 유지, 토큰 교체와 부정 사용 방지에 이용합니다. 서버 접속 과정에서 IP 주소, 접속 시각, 요청 경로·상태 등의 운영 로그가 처리될 수 있습니다.
  • 기기 내부: 로그인 유지용 토큰은 iOS Keychain에, 아직 서버에 전송하지 못한 회원 게임 결과는 앱 저장소에 보관합니다. 탈퇴 성공 시 현재 기기의 해당 계정 토큰과 전송 대기 결과를 지웁니다. 다른 기기에 남은 로그인 정보는 서버 인증에 사용할 수 없게 됩니다.
  • 회원가입 없이 이용: 회원 기능을 사용하지 않아도 앱의 단어 게임을 이용할 수 있습니다. 비회원 게임 기록을 회원 서버 계정으로 저장하지 않습니다. 광고 SDK의 정보 처리는 아래 3항을 따릅니다.

2. 다른 이용자에게 표시되는 정보

로그인한 이용자는 랭킹에서 다른 회원의 닉네임, 학생 그룹, 선택 입력한 출신, 점수, 순위, 레벨·계급과 회원 식별 ID를 조회할 수 있습니다. 이메일, 비밀번호와 로그인 토큰은 랭킹에 공개하지 않습니다. 닉네임과 출신에는 실명이나 연락처 등 공개하고 싶지 않은 정보를 넣지 마세요.

3. 서버 운영 및 광고 서비스

  • Amazon Web Services(AWS): 한국 서울 리전의 Lightsail 서버와 비공개 백업 저장소에서 회원 DB를 호스팅하고 백업합니다. 회사는 운영에 필요한 접근만 허용합니다. AWS 개인정보 안내
  • Google AdMob · User Messaging Platform(UMP): 광고 표시 및 지역별 광고 동의 선택을 위해 Google SDK를 사용합니다. 광고 SDK는 IP 주소와 이를 통한 대략적 위치, 기기 식별자, 광고 노출·상호작용, 앱 이용·성능 및 오류 진단 정보를 처리할 수 있습니다. 광고 제공·측정, 부정 사용 방지와 서비스 개선 등에 사용되며 Google 또는 Google의 광고 파트너가 처리할 수 있습니다. Google의 처리 과정에서 정보가 한국 외 국가로 전송·보관될 수 있습니다. 회사는 회원 이메일, 비밀번호, 닉네임과 학습 점수를 광고 SDK에 전달하도록 구현하지 않았습니다. Google 개인정보처리방침 · AdMob SDK 정보 처리 안내

광고 동의 선택이 제공되는 지역에서는 안내 화면에서 선택할 수 있고, 게임 선택 화면에 “광고 개인정보 설정”이 표시되는 경우 해당 버튼으로 선택을 변경할 수 있습니다. 기기 설정의 개인정보 보호 옵션도 이용할 수 있습니다. 광고 동의를 바꾸거나 회원 탈퇴를 하더라도 Google이 별도로 보관하는 정보의 삭제에는 Google의 절차와 보관 정책이 적용됩니다.

4. 보관 기간과 파기

  • 회원 DB: 서비스 이용 기간 동안 보관하며, 회원 탈퇴가 성공하면 회원 정보, 게임 기록·점수와 모든 로그인·토큰 기록을 운영 DB에서 즉시 삭제합니다. 삭제한 계정과 점수는 앱에서 복구할 수 없습니다. 같은 이메일로 다시 가입하면 새로운 계정으로 시작합니다.
  • 백업: 삭제 전에 만들어진 재해 복구용 백업에는 정보가 일시적으로 남을 수 있습니다. 원격 백업은 7일, 서버 내부 백업은 2일 보관 기준으로 매일 정리하므로 다음 정리 시점까지 남아 있을 수 있습니다. 백업은 장애 복구 목적 외에는 이용하지 않고 접근을 제한합니다.
  • 운영 로그: 각 컨테이너 로그를 파일당 10MB, 최대 3개로 제한하여 오래된 로그부터 순환 삭제합니다. 로그에는 비밀번호와 토큰 원문을 기록하지 않도록 구성합니다.

전자 정보는 운영 DB에서 삭제하고, 보관 기간이 지난 백업 파일은 삭제하는 방법으로 파기합니다. 법령에 따라 별도 보관이 필요한 상황이 발생하면 해당 근거, 항목과 기간을 이용자에게 안내합니다.

5. 이용자의 권리와 회원 탈퇴

앱의 “내 정보”에서 회원 정보를 확인하고 “회원 탈퇴”로 개인정보 삭제를 요청·완료할 수 있습니다. 다른 사람의 임의 삭제를 막기 위해 로그인과 비밀번호를 다시 확인합니다. 삭제 요청이 실패하면 완료로 표시하지 않으며 다시 시도할 수 있습니다.

개인정보 열람·정정·삭제·처리 정지 또는 동의 철회에 관한 문의는 아래 이메일로 보내주세요. 본인 확인 후 처리하고 결과를 안내합니다. 문의 이메일에 비밀번호나 로그인 토큰을 보내지 마세요.

6. 보호 조치

앱과 운영 API 사이에 HTTPS를 적용하고, 비밀번호를 해시로 저장합니다. DB를 외부에 직접 공개하지 않으며, 로그인 토큰 만료·교체, 인증 요청 제한, 서버와 비공개 백업의 접근 제한을 적용합니다.
